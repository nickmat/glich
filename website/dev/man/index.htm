The Glich Script Language

Glich is a compact scripting language designed for working with dates, ranges, sets, and calendar systems. It began inside the HistoryCal application, which needed a way to interpret “date phrases” — short expressions describing eras, ranges, unions, intersections, and historical periods. To support these expressions, HistoryCal required a small but expressive language, and that language eventually became Glich.

The language naturally falls into two layers: a core language for general purpose programming, and an extension for calendar‑specific functionality.

This manual describes the script language itself: first the core Glich language, then the Hics extension and the library of available calendar schemes. A tutorial using the Gliched program, an IDE which is under development.

The documentation here is part of the development section of the website. Once the language is frozen, a stable copy will be placed on the main site, and further work will continue in the development area.
