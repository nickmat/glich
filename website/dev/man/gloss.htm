Introduction

The Glich script, Hics extension and documentation gives some precise definitions to certain words or phrases.

Date Phrase
A compact textual expression describing dates, ranges, or sets of dates. A date phrase is parsed into Glich code and evaluated. For details see the Date Phrase page.
Date Signature
A date signature is a string combining a calendar scheme and format to define a text representation of a date. It is often used with Glich script functions to specify a date format for parsing or formatting dates. As in @text.g:mdy(@date.j:ymd( "1750 May 5" )). It may also be used within a date phrase to specify the scheme and format of a date within that phrase. In this case it precedes the date and is terminated with a '#' character. For example, "h:dmy# 11 Tishrei 5787".
Dual Dates
Showing a date using two different year systems. Typically used when both the civil year and the historic year are given, separated by a '/' character.
Element
A part of a date’s text description. When parsing a date, elements are matched to the fields within the scheme's record.
Endpoint
The boundary value of a Range. Endpoints may be finite integers or special Field values.
Epoch
The mathematical starting point of a calendar scheme. All scheme calculations are performed relative to the epoch.
Era
A period of time defined within a calendar scheme. Eras may represent reigns, historical periods, or scheme-specific subdivisions.
Field (Interval)
A Field used as an endpoint of a Range. Interval Fields may be integers, -∞, +∞, or an indeterminate value. They form the basic type used for interval and set operations.
Field (Scheme Record)
A Field used within a Scheme Record. Record Fields hold the individual components of a date, such as year, month, or day. These values are finite integers defined by the scheme.
Interval Algebra
The set of operations defined on Ranges and Rlists. Includes union, intersection, difference, and normalisation.
Julian Day Number
The continuous day count used internally by Glich's Hics extension. Abbreviated to jdn. Formally defined here.
HistoryCal Script
The original scripting language used by the Cal library. Modern Glich syntax derives from this language. Files containing HistoryCal Script use the .hcs extension.
Infinity
Sentinel values representing unbounded endpoints. Used for open-ended historical or temporal ranges.
Normalisation
The process of merging overlapping or adjacent Ranges in an Rlist. Ensures rlists remain disjoint and ordered.
Pseudo Date
A text representation of a scheme’s output or input format. For example, "dd Mon yyyy" describes a formatting pattern rather than a specific date.
Scheme
A calendar definition used by the Hics system. A scheme specifies the epoch, structure, leap rules, and formatting behaviour.
Scheme Record
A Scheme Record is the collection of Record Fields which define a date for a particular calendar scheme. Each field holds one component of the date, such as year, month, or day, according to the rules of the scheme.
Scheme Usable Range
The period during which a calendar scheme was historically in use. Dates outside this range may be valid mathematically but not historically.
Scheme Working Range
The range of dates for which conversions are defined for a scheme. This may extend beyond the scheme’s usable range.
Range
A range is a closed integer interval of the form [a..b], including both endpoints. Ranges are used to represent spans of discrete values such as days, months, or years.
Rlist
An rlist is a normalised list of non-overlapping Ranges. It represents a disjoint interval set used for union, intersection, and other interval operations.
Unknown
A special Field value indicating an indeterminate or undefined endpoint. Represented by the '?' character in the script.
